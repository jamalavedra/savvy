## Windows 11 integration with `feat/windows-support`

The combined branch is [PR #40](https://github.com/jamalavedra/savvy/pull/40) against `feat/windows-support`. It was tested on Windows 11 x64 build 26300.9711 in an isolated checkout. The combined managed CRM and document fixture passed with native Windows code: it imported a synthetic HubSpot company and Google Drive document into the client folder, indexed their Markdown copies, sent excerpts through the managed recommendation path, and verified a citation to the imported local source. With the Composio fixture unavailable, the same test marked the retained copy stale, excluded it when chosen, and completed advice without a provider request during the meeting. `pnpm --dir backend test:connected-e2e` passed 1/1. The Windows React suite passed 141/141 with `pnpm exec vitest run --maxWorkers=2`; the Windows audio crate passed 7/7 tests.

This identified and fixed three Windows-specific blockers in the integration branch: the native test executable lacked a Common Controls v6 manifest, Tauri mock IPC tests used the macOS origin, and the Windows document scanner had no verified file-open implementation. The verified open checks reparse points and the opened handle's resolved path so imported files can be indexed without following redirected paths.

The full Windows backend suite passed 114 tests, with 2 opt-in tests skipped. Root and backend TypeScript checks, the Vite production build, `cargo check -p savvy --lib --locked`, `cargo build -p savvy --locked`, and Rust formatting passed. `cargo test --workspace --locked -- --skip disposable_credential_can_be_replaced_and_deleted` passed the rest of the Rust workspace; the excluded Windows Credential Manager test passed 1/1 in the signed-in desktop session. It cannot access the credential vault from the SSH logon session, where it returns `0x80070520`, so the normal suite marks it interactive-only. The temporary scheduled task used for that interactive test was removed. Windows audio tests passed 7/7 after the idle-loopback fix; local lint, formatting, and Rust Clippy passed.

The installed NSIS integration app signed into the real staging account through Edge OAuth, received its deep link in the already-running app, and stored the managed token in Windows Credential Manager. Its Prepare view opened a Composio Connect Link for Notion. The authorized Notion account granted access to the existing fictional `Savvy connector test — Acme renewal` page.
